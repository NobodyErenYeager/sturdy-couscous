Below are all the commands used in this course section :-


django-admin startproject <project-name> ==> TO CREATE A DJANGO PROJECT. CHANGE <project-name> with  name which you want for your Django project.

python manage.py startapp <app-name> ==> TO CREATE AN APP AND CHANGE <app-name> with your app name.

python manage.py runserver ==> TO RUN THE SERVER.
