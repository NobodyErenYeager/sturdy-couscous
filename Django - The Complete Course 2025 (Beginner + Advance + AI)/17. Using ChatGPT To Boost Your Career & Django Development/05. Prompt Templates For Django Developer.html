Global Prompt For Everything

Act as an expert django developer Generate a view which handles post request with files and then save them into model named post which has fields(post_title,post_content,post_img). And after form submission and saving files redirect user to root url of website Explain each code and everything step by step.

Prompt For Specific Case

Act as an expert django developer who is expert in working with Database in django. TASK: I want to store user related data like username, date of birth, number of jobs user has done, user age & number of user childrens. I am new to django so help me in using the right model field type and arguments. Constraints: Explain what & why step by step for example explain what & why of each model field type like why using this model field and also explain what & why behind every argument used in model field type

Planning & Generating Models

Act as an expert django dev who is very experienced in working with django models & django orm. Task: I am planning to build blog website in django with features such as posts, comments. I have created the django project named blog and an app inside it named posts which will contain all the posts and comments funcitonality. Help me in planning the models and generate the code for models. Constraints: Explain what & why of everything step by step. Also explain the field types and arguments you will use.

Deciding Model Field Type

I want to store User age in seconds in my django model. Help me in deciding which model field type to use and which arguments to use.

Relationships

Act as an expert django dev who is very experienced in working with django models & model relationships, I have two models products and comments. User can comment on any post. Help me in deciding which model relationship to use Explain the what & why behind the model relationship type and why using it and also the arguments
